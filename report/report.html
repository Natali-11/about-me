Цель работы

Познакомиться со структурой HTML-документа, создать страничку со своей презентацией, проявить творческий подход.

Постановка задачи

Для закрепления знаний о структуре и особенностях HTML-документов выполнить задания на сайте htmlacademy.ru.

Сформировать страницу о себе с текстом, ссылками и фотографиями.

Сформировать страницу с отчётом по работе в виде HTML-документа с сохранением всех атрибутов отчёта: титульным листом, текстом отчёта с изображениями.

Ход работы

  1. Пройдены бесплатные курсы на сайте htmlacademy.ru по HTML и CSS. (Курсы, отмеченные зелёным, пройдены не до конца, так как для выполнения остальных заданий требуется подписка.)
  1. Страница «О себе» разработана с использованием фреймворка Fusion.js (на основе React) и опубликована на облачной платформе Render по адресу: https://about-me-natali.onrender.com.

    Исходный код проекта размещён в репозитории GitHub: https://github.com/Natali-11/about-me. Основной код страницы находится в файле src/pages/home.js.

    Сайт размещён на бесплатном тарифе Render, на котором сервер автоматически приостанавливается после 15 минут без обращений. Поэтому при первом открытии после простоя загрузка страницы может занять до одной минуты. Последующие обращения обрабатываются без задержки.
